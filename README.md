# 📝 Todolist React

Une application simple de gestion de tâches (to-do list) réalisée en **React**.  
Elle stocke les données **localement dans le navigateur (localStorage)**, donc aucune base de données ou connexion n’est nécessaire.

## Fonctionnalités

- **Ajouter** une nouvelle tâche
- **Marquer** une tâche comme complétée ou non
- **Filtrer** (toutes, actives, complétées)
- **Supprimer** une tâche individuelle
- **Supprimer toutes les tâches complétées**
- **Sauvegarde automatique** dans le navigateur grâce à `localStorage`

---

## 🛠️ Stack technique

- [React](https://react.dev/) (hooks `useState`, `useEffect`)
- [SCSS](https://sass-lang.com/) pour la mise en forme
- `localStorage` pour la persistance des données
- Outils de build :  
  - [Create React App](https://create-react-app.dev/) **ou** [Vite](https://vitejs.dev/)
